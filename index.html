Integration Recipes

The exported files contain self-contained, inline CSS rules and filters, making them fully standalone assets. Choose the method that fits your stack:

  • HTML Image Element: Simply save the SVG to your public asset path and load it via <img src="assets/spinner.svg" />.
  • React / Vue Components: Copy the code inside the SVG tag, replace XML casing with JSX casing, and render directly for complete inline CSS control.
  • CSS Backgrounds: Stringify the SVG XML and encode it as a DataURI for background image variables.
